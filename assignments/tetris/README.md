# TETЯIS

1988년 아케이드/패미컴 시절 테트리스 분위기를 재현한 브라우저 테트리스. `index.html` 하나로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 첫 키 입력 이후 사운드가 재생됩니다.

## 조작

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| ↓ | 소프트 드롭 |
| Space | 하드 드롭 |
| ↑ / X | 시계 방향 회전 |
| Z / Ctrl | 반시계 방향 회전 |
| C / Shift | 홀드 |
| P / Esc | 일시정지 |
| M | 사운드 켜기/끄기 |
| 타이틀에서 ← → | 시작 레벨 선택 (0–19) |
| Enter | 시작 |

## 기능

- 256×224 도트 화면, NES 팔레트 블록, 크렘린 야경 배경, 블록으로 그린 TETЯIS 로고
- 코로베이니키 BGM(칩튠 합성), 블록이 위험 높이까지 쌓이면 템포 상승, 효과음
- SRS 회전 + 월킥, 인피니티(이동·회전 시 락 딜레이 초기화), 하드 드롭, 홀드, 고스트, NEXT 3개
- T-스핀(미니 포함), 다른 블록의 올-스핀, Back-to-Back, 콤보, 퍼펙트 클리어 점수
- 타이틀에서 10초 동안 입력이 없으면 AI 데모 플레이
