# TETЯIS

1988년 아케이드/패미컴 시절 테트리스 분위기를 재현한 브라우저 테트리스. `index.html` 하나로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 첫 키 입력 이후 사운드가 재생됩니다.

## 조작

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| ↓ | 소프트 드롭 |
| Space | 하드 드롭 |
| ↑ / X | 시계 방향 회전 |
| Z / Ctrl | 반시계 방향 회전 |
| C / Shift | 홀드 |
| P / Esc | 일시정지 |
| M | 사운드 켜기/끄기 |
| 타이틀에서 ↑ ↓ | 항목 이동 (모드 / 레벨·스테이지 / 음악) |
| 타이틀에서 ← → | 선택값 변경 |
| Enter | 시작 |

## 모드

- **MARATHON**: 끝없이 쌓는 기본 모드. 10줄마다 레벨이 오릅니다 (시작 레벨 0–19).
- **STAGE** (기본): 20개 스테이지. 각 스테이지는 정해진 방해 블록이 깔린 채 시작하고, 목표 줄 수를 지우면 클리어입니다.
  스테이지가 오를수록 속도·목표 줄 수·방해 블록 높이가 늘어나고, 클리어 시 남은 빈 줄에 비례한 보너스를 받습니다.
  스테이지를 클리어하면 무대 위에서 코사크 댄서 3명이 춤추는 막간 연출이 나옵니다 (Enter로 건너뛰기).
  스테이지마다 배경 하늘과 음악이 바뀝니다.

## 음악

| 곡 | 설명 |
|---|---|
| KOROBEINIKI | 러시아 민요 「코로베이니키」 |
| KALINKA | 러시아 민요 「칼린카」(1860) 후렴 편곡, 반복할 때마다 점점 빨라짐 |
| TROIKA | 빠른 갤럽 리듬 (창작곡) |
| VOLGA | 느린 3/4 왈츠 (창작곡) |
| MATRYOSHKA | 통통 튀는 마이너 댄스 (창작곡) |
| KAZACHOK | 코사크 춤풍 (창작곡) |

모두 Web Audio로 실시간 합성하는 칩튠이며, 블록이 위험 높이까지 쌓이면 템포가 빨라집니다.

음색은 NES(2A03) 음원 구성을 흉내 냅니다.

- 펄스 1: 리드 멜로디. 12.5/25/50% 듀티를 섹션마다 바꾸고, 긴 음에는 늦게 걸리는 비브라토와 NES식 볼륨 엔벨로프
- 펄스 2: 리드를 한 박 늦게 작게 따라 하는 에코 (VOLGA는 한 옥타브 아래 더블링)
- 삼각파: 4비트 계단식 삼각파 베이스, 킥·탐도 삼각파 피치 하강으로 표현
- 노이즈: 15비트 LFSR 노이즈 (스네어는 롱 모드, 하이햇은 쇳소리 나는 숏 모드)
- 각 섹션 끝마다 스네어 + 탐 드럼 필인, 출력단 하이패스/로우패스 필터

## 테스트 모드

타이틀에서 **T**를 누르면 TEST MODE가 켜집니다 (다시 누르면 꺼짐, 주소 끝에 `?test`를 붙여 열어도 켜짐).
테스트 모드에서는 스테이지 모드 플레이 중 **K**를 눌러 현재 스테이지를 바로 클리어할 수 있습니다.
댄서 연출과 스테이지 진행을 빠르게 확인할 때 쓰세요.

## 기능

- 256×224 도트 화면, NES 팔레트 블록, 크렘린 야경 배경(4가지 하늘), 블록으로 그린 TETЯIS 로고
- SRS 회전 + 월킥, 인피니티(이동·회전 시 락 딜레이 초기화), 하드 드롭, 홀드, 고스트, NEXT 3개
- T-스핀(미니 포함), 다른 블록의 올-스핀, Back-to-Back, 콤보, 퍼펙트 클리어 점수
- 타이틀에서 10초 동안 입력이 없으면 AI 데모 플레이
- 모드별 최고 점수와 타이틀 선택값 저장
