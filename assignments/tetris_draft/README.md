# Tetris

브라우저에서 바로 실행되는 테트리스. `index.html` 하나로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다.

## 조작

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| ↓ | 소프트 드롭 |
| Space | 하드 드롭 |
| ↑ / X | 시계 방향 회전 |
| Z | 반시계 방향 회전 |
| C / Shift | 홀드 |
| P / Esc | 일시정지 |
| Enter | 시작 |

## 기능

- 7-bag 랜덤, SRS 회전 + 월킥
- 고스트 블록, 다음 블록 5개 미리보기, 홀드
- 레벨에 따라 빨라지는 낙하 속도, 최고 점수 저장
